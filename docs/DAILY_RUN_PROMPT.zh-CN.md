# 平台已建成并验收后，每个新项目的输入模板

使用 replica-factory，读取 project.json 和本仓库 AGENTS.md。

参考网站：填写 URL。
批准范围：填写站点路径、页面类型、桌面/移动与交互范围。
开发 WordPress：填写 URL、路径或已配置 adapter 名。
GitHub 仓库：填写仓库，使用当前已登录的受限 gh 身份，不读取/打印 token。
预览发布：使用已经配置的 preview 环境与 adapter。
授权素材：填写自有/获准素材来源；未授权素材不得抓取复用。
商品数据：填写自己的数据源及参考 fixture 策略。
预算：读取 project.json，不擅自扩大。
生产：仅创建待批准发布，不直接部署。

先检查平台 adapter 是否完整和 toolchain 版本是否匹配；不完整则 BLOCKED 并指出缺项。
就绪后从 PREFLIGHT 开始，按冻结范围采集、实现、评估并有界修复。
分组件提交代码，自动触发 CI 和隔离预览复验。
每轮记录状态，进程中断后能恢复；凭据、授权或预算阻塞时停止，不假装通过。
结束时给出候选摘要、预览地址、覆盖矩阵、diff 和全部残差。
