# Visual Repair
先核对报告的 candidate_id、baseline_sha256、policy_sha256 与当前工作对应。
优先修复字体未加载、容器宽度、全局间距等根因，再修复图片裁剪、图标与细节。
一次选一个组件或同一根因影响的少量组件；记录改动前后的差异和影响面。
使用参考图/实际图/diff，不只读模型自然语言评分。
不得添加大面积覆盖层、隐藏失败元素、把页面做成截图或将原站 iframe 嵌入。
不得改测试范围、掩码、阈值或基准；需要改变规格时提出单独规格变更请求。
每轮由外部评估器重新运行。只有可靠测量改善才算进展；连续无改善或预算耗尽退出。
浏览器渲染、地区差异、支付控件等无法稳定复现时提供确切残差，不能伪称 100%。
